Constraints

Bounds shape every wheel.

Years, months, days, hours and minutes are derived from the actual allowed interval. Invalid options disappear instead of being accepted and clamped later.

Vanilla

Small public surface.

import { DatePicker } from '@shelamkoff/date-picker'
import '@shelamkoff/date-picker/style.css'

const picker = new DatePicker(host, {
  enableTime: true,
  minuteStep: 5,
  clearable: true,
  showNow: true,
  onChange(value, reason) {
    console.log(value, reason)
  },
})

Vue 3

A thin adapter, not a second picker.

<script setup lang="ts">
import { shallowRef } from 'vue'
import { DatePicker } from '@shelamkoff/vue-date-picker'
import '@shelamkoff/vue-date-picker/style.css'

const value = shallowRef<Date | null>(null)
</script>

<template>
  <DatePicker v-model="value" enable-time clearable show-now />
</template>
