Cyclic bounds

Cross a boundary and continue from the other side.

This date-only picker is constrained to the current calendar month and runs with loop: true. Scroll past the last selectable date to jump to the first; scroll above the first to jump to the last.

Vanilla TypeScript

Small public surface.

import { DatePicker } from '@shelamkoff/date-picker'
import '@shelamkoff/date-picker/style.css'

const picker = new DatePicker(host, {
  enableTime: true,
  minuteStep: 5,
  monthDisplay: 'long',
  clearable: true,
  showNow: true,
  onChange(value, reason) {
    console.log(value, reason)
  },
})

Headless core

Use the date logic without the DOM widget.

import { createDatePicker } from '@shelamkoff/date-picker/core'

const controller = createDatePicker({
  enableTime: true,
  minuteStep: 5,
})

controller.open()
console.log(controller.snapshot.columns)
